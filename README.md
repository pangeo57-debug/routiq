# RoutePal

*🇬🇷 Ελληνικά | [🇬🇧 English](./README.en.md)*

Εφαρμογή προγραμματισμού και βελτιστοποίησης δρομολογίων για ιδιωτικούς εκπαιδευτικούς και άλλους ελεύθερους επαγγελματίες (φυσιοθεραπευτές, personal trainers, κ.ά.) που επισκέπτονται πελάτες/μαθητές κατ' οίκον.

**Live**: https://pangeo57-debug.github.io/routiq/routiq.html

## Τι κάνει

- Δημιουργεί αυτόματα εβδομαδιαίο πρόγραμμα μαθημάτων, σεβόμενη τη διαθεσιμότητα κάθε μαθητή και το ωράριο εργασίας σου
- Βελτιστοποιεί τη σειρά επισκέψεων ώστε να ελαχιστοποιούνται τα χιλιόμετρα/χρόνος μετακίνησης (πραγματικά δεδομένα δρόμου μέσω OSRM/HERE, όχι απλή ευθεία απόσταση)
- Υποστηρίζει ομαδικά μαθήματα, ζευγάρια μαθητών, συνδυαστικά μπλοκ ωρών
- Εξαγωγή προγράμματος σε PDF
- Χάρτης με τοποθεσίες μαθητών και προτεινόμενη διαδρομή
- Πολυγλωσσική διεπαφή (Ελληνικά, Αγγλικά, Γαλλικά, Γερμανικά)
- Dark mode
- Λειτουργεί ως PWA — εγκαθίσταται στην αρχική οθόνη του κινητού σαν κανονική εφαρμογή

## Τεχνική αρχιτεκτονική

**Single-file εφαρμογή, χωρίς backend (προς το παρόν).** Όλη η εφαρμογή — HTML, CSS, JavaScript — βρίσκεται σε ένα αρχείο: [`routiq.html`](./routiq.html). Δεν υπάρχει build step, δεν χρειάζεται `npm install`.

```
routiq.html          → ολόκληρη η εφαρμογή
sw.js                 → service worker (network-first: φρέσκο online, λειτουργεί offline)
manifest.json         → PWA manifest (εικονίδιο, όνομα, χρώματα)
icon-*.png, apple-touch-icon.png → εικονίδια εφαρμογής
PRIVACY.md, TERMS.md → πρόχειρα νομικά κείμενα (ΧΡΕΙΑΖΟΝΤΑΙ ΕΛΕΓΧΟ ΔΙΚΗΓΟΡΟΥ πριν χρησιμοποιηθούν)
```

### Αποθήκευση δεδομένων

Όλα τα δεδομένα (μαθητές, πρόγραμμα, ρυθμίσεις) αποθηκεύονται **τοπικά στη συσκευή** του χρήστη (`localStorage`) — δεν υπάρχει κεντρικός server/βάση δεδομένων ακόμα. Κάθε χρήστης βλέπει μόνο τα δικά του δεδομένα, στη δική του συσκευή.

| Υπηρεσία | Σκοπός | Κόστος |
|---|---|---|
| [Nominatim](https://nominatim.openstreetmap.org) (OpenStreetMap) | Γεωκωδικοποίηση διευθύνσεων (προεπιλογή) | Δωρεάν |

| jsPDF + html2canvas | Εξαγωγή προγράμματος σε PDF | Δωρεάν, open source |

Δεν χρησιμοποιείται κανένα Google API — αποφεύγεται σκόπιμα λόγω κόστους σε κλίμακα (δες συζήτηση στο ιστορικό του project).

### Αλγόριθμος προγραμματισμού

Πολυφασικός αλγόριθμος (`Scheduler` object μέσα στο `routiq.html`):

1. **Backtracking CSP** (πολλαπλές τυχαίες προσπάθειες) — αρχική τοποθέτηση, μεγιστοποιεί τον αριθμό τοποθετημένων μαθητών
2. **Geographic optimization** — nearest-neighbor + cross-day moves/swaps για μείωση χιλιομέτρων
3. **Simulated Annealing** — καλύτερη σειρά διαδρομής
4. **Repair passes** — προσπάθεια τοποθέτησης όσων έμειναν έξω
5. **LNS (Large Neighborhood Search)** — destroy-repair για δύσκολες περιπτώσεις, με "επίμονη αναζήτηση" έως 7 λεπτά αν χρειαστεί
6. **`enforceConstraints()`** — τελικό δίχτυ ασφαλείας: αφαιρεί οποιαδήποτε τοποθέτηση παραβιάζει τη διαθεσιμότητα μαθητή, ξαναπροσπαθεί αλλού

## Ανάπτυξη

Δεν χρειάζεται τίποτα ιδιαίτερο — άνοιξε το `routiq.html` σε browser, ή τρέξε έναν απλό local server (π.χ. `python3 -m http.server`) για σωστή λειτουργία του Service Worker/manifest.

### Testing

```bash
npm test
```

46 τεστ, καμία εξάρτηση — μόνο το built-in `node:test` (Node 18+).

Επειδή η εφαρμογή είναι ένα αρχείο HTML, τα τεστ φορτώνουν το πραγματικό
`<script>` σε Node `vm` sandbox με stubbed browser API (`test/harness.js`).
Τρέχουν πάνω στον **αληθινό κώδικα**, όχι σε αντίγραφο.

| Αρχείο | Τι καλύπτει |
|---|---|
| `test/scheduler.test.js` | Κανόνες προγράμματος: μπλοκαρισμένες ώρες, διαθεσιμότητα, ζευγάρια/ομάδες, δίωρα, χρόνοι μετακίνησης |
| `test/data.test.js` | Απώλεια δεδομένων: ζευγάρωμα, διαγραφή, export/import, παλιά αποθηκευμένα δεδομένα |
| `test/rendering.test.js` | XSS escaping, αναζήτηση διεύθυνσης, ανθεκτικότητα δικτύου |
| `test/i18n.test.js` | Πληρότητα μεταφράσεων και στις 4 γλώσσες |

`test/invariants.js` περιέχει έναν **ανεξάρτητο** ελεγκτή κανόνων — σκόπιμα
ξεχωριστό από το `verifySchedule()` της εφαρμογής, ώστε να πιάνει και την
περίπτωση όπου ο αλγόριθμος και ο αυτοέλεγχός του κάνουν το *ίδιο* λάθος
(ακριβώς αυτό συνέβη με τις μπλοκαρισμένες ώρες).

Κάθε τεστ αντιστοιχεί σε bug που όντως εμφανίστηκε — είναι regression suite,
όχι θεωρητική άσκηση.

### Deployment

Push στο branch `main` → αυτόματο deploy μέσω GitHub Pages, ζωντανό μέσα σε 30-60 δευτερόλεπτα.

Ο service worker είναι network-first, οπότε μια συσκευή με σήμα παίρνει πάντα την τελευταία έκδοση χωρίς hard refresh. (Συσκευές που είχαν τον παλιό, blob-based worker χρειάζονται ένα τελευταίο hard refresh για να περάσουν στον νέο.)
