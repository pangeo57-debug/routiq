# DropOff

Εφαρμογή βελτιστοποίησης διαδρομών ντελίβερι για μαγαζιά με υπηρεσία delivery
(εστιατόρια κ.λπ.). Αδερφό project του [RoutePal](https://github.com/pangeo57-debug/routiq),
ίδιο πνεύμα (single-file HTML/JS, χωρίς build step, PWA), διαφορετικό πρόβλημα:
πολλαπλοί ντελιβεράδες, δυναμικές παραγγελίες μέσα στη μέρα, multi-vehicle
routing αντί για εβδομαδιαίο πρόγραμμα.

## Χρήση

Άνοιξε το `dropoff.html` σε browser (ή σέρβιρέ το static, π.χ.
`python3 -m http.server`). Δεν χρειάζεται build step ή εγκατάσταση.

## Φάση 1 (τρέχουσα) — χειροκίνητη εισαγωγή παραγγελιών

- **Παραγγελίες**: χειροκίνητη προσθήκη (όνομα, διεύθυνση με autocomplete,
  σημειώσεις), σήμανση παράδοσης, διαγραφή.
- **Διαδρομές**: καταμερισμός + σειρά στάσεων ανά οδηγό μέσω του αλγορίθμου
  **Clarke & Wright Savings (1964)** — του κλασικού ακαδημαϊκού αλγορίθμου
  κατασκευής για ακριβώς αυτό το πρόβλημα (N στάσεις, K οχήματα, ένα depot):
  κάθε παραγγελία ξεκινά ως δική της γύρος-επιστροφή στο depot, και μετά
  συγχωνεύονται διαδοχικά τα ζεύγη διαδρομών με το μεγαλύτερο "saving"
  (dist(depot,i) + dist(depot,j) − dist(i,j)) μέχρι να μείνουν ακριβώς τόσες
  διαδρομές όσοι οι ενεργοί οδηγοί. Ακολουθεί βελτιστοποίηση 2-opt σε κάθε
  διαδρομή, πάνω σε πραγματικές οδικές αποστάσεις/χρόνους από το OSRM. Νέες
  παραγγελίες που έρχονται ενώ υπάρχει ήδη ενεργή διαδρομή μπαίνουν στην πιο
  φθηνή θέση μέσω cheapest-insertion, χωρίς πλήρη επαναβελτιστοποίηση.
- **Πίνακας εξοικονόμησης**: μετά από κάθε βελτιστοποίηση, η οθόνη Διαδρομές
  δείχνει πόσα χιλιόμετρα/λεπτά/€ βενζίνης γλύτωσε ο Clarke-Wright αλγόριθμος
  σε σύγκριση με το να πηγαίνει κάθε ντελιβεράς μόνος του, γύρο-γύρο, για κάθε
  παραγγελία ξεχωριστά — κάνει ορατή την ίδια την αξία της εφαρμογής αντί να
  μένει κρυφή λεπτομέρεια υλοποίησης.
- **Οδηγοί**: προσθήκη/αφαίρεση, ενεργοποίηση/απενεργοποίηση.
- **Ρυθμίσεις**: διεύθυνση μαγαζιού (depot), προαιρετικό HERE API key για
  ακριβέστερη αναζήτηση διευθύνσεων, κατανάλωση/τιμή καυσίμου (για τον
  υπολογισμό εξοικονόμησης σε €), γλώσσα (EL/EN).

Γεωκωδικοποίηση μέσω Nominatim (OpenStreetMap, δωρεάν) ή HERE Autosuggest αν
έχει οριστεί key. Πραγματικές οδικές αποστάσεις/διάρκειες μέσω του δημόσιου
OSRM server. Αν μια παραγγελία δεν γεωκωδικοποιηθεί, εμφανίζεται σαφώς ως
"χωρίς διεύθυνση" και δεν εντάσσεται σιωπηλά στη βελτιστοποίηση.

## Φάση 2 (μελλοντικό)

Σύνδεση με τα partner/merchant API των Wolt και efood (πιθανώς webhook-based),
κάτι που θα απαιτήσει ένα μικρό backend για να δέχεται τα webhooks — δεν
καλύπτεται από static HTML μόνο. Το data model της Φάσης 1 έχει ήδη πεδίο
`source` (`'manual'` προς το παρόν) και `externalId` ώστε να μπορεί να
τροφοδοτηθεί αυτόματα αργότερα χωρίς ανατροπή της δομής.

## Testing

```
node test/run-tests.js
```

Node `vm`-based harness: εξάγει το inline `<script>` από το `dropoff.html`,
το τρέχει σε sandboxed context με stubbed `document`/`localStorage`/`fetch`,
και επαληθεύει `esc()`, γεωμετρία (haversine/bearing), τον αλγόριθμο VRP
(assign/nearestNeighbor/twoOpt/cheapestInsertion), i18n, storage round-trip,
και ένα end-to-end optimize flow — χωρίς browser.

## Αρχεία

- `dropoff.html` — όλη η εφαρμογή (HTML/CSS/JS), single file.
- `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — PWA assets.
- `scripts/generate-icons.js` — παράγει τα PNG icons χωρίς εξωτερικές βιβλιοθήκες.
- `test/run-tests.js` — ο Node vm test harness.
